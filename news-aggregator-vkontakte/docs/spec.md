# Техническое задание на создание автоматизированной системы «Город Говорит»

## Назначение и цели создания системы

Платформа создается для: 

− Автоматизированного сбора публикаций из заданного списка источников;

− Семантического анализа текста и категоризации контента;

− Формирования ленты публикаций для пользователей;

− Предоставления доступа к системе через интерфейс ВКонтакте мини-приложения.

## Технические требования

### Функциональные требования

Пользователь получает возможность выполнять следующие действия:

− Просматривать хронологическую ленту публикаций;

− Осуществлять фильтрацию публикаций в ленте по категориям;

− Переходить по ссылке на публикацию в первоисточнике; 

− Просматривать страницу «Тренды»;

− Осуществлять фильтрацию трендов по категориям;

− Добавлять/убирать группы, которые отображаются в ленте;

− Добавлять/убирать категории из доступных;

− Просматривать страницу «Источники».

### Нефункциональные требования

Приложение должно включать следующие основные страницы:

− Лента - хронологическая лента публикаций из всех подключенных групп ВКонтакте. Доступен фильтр по категориям. 
Карточка публикации: имя автора, фото/логотип, текст публикации, изображение (при наличии), ссылка на первоисточник, пагинация – прокрутка;

− Тренды - тренды в новостях на основе анализа публикаций. Карточки с названиями трендов и метриками (количество просмотров). 
Доступен фильтр по категориям. Модальное окно – развёрнутое описание выбранного тренда и ссылки на публикации, где встречается этот тренд; 

− Настройки - список всех подключенных источников. Сетка каналов: изображение с названием.

Архитектура должна быть реализована на языке Python с использованием микросервисного подхода для обеспечения модульности. Интерфейс системы должен быть реализован в формате мини-приложения для бесшовной работы внутри социальной сети «Вконтакте». Время отклика интерфейса не должно превышать 2 секунд. Использование внешних API должно быть реализовано с обработкой возможных задержек или временной недоступности сервисов.

### Требования к источникам новостей

− Количество подписчиков: не менее 500. Оптимальное значение: 1500+;

− Среднее количество просмотров на постах: не менее 200. Оптимальное значение: 1 000+;

− Частота публикаций: не реже 1 раз в неделю. Оптимальное значение: 1 пост в день;
  
− Канал должен иметь идентифицируемого автора или редакцию;
  
− Наличие комментариев, реакций, репостов от подписчиков;

− Отсутствие материалов, нарушающих законодательство РФ.

### Требования к интерфейсу

− Минималистичный, адаптивный дизайн в стилистике ВКонтакте;

− Использование UI/UX компонентов ВКонтакте.

| Этап | Содержание | Результат |

| 1 | Сбор и анализ материалов | Перечень групп ВКонтакте для использования. Не менее 20, не более 100 |

| 6 | Деплой | Обратная связь от пользователей |
