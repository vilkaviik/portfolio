## AR Beauty Guide
Проектирование и разработка мобильного приложения с дополненной реальностью для распознавания косметической продукции. Учебный проект.
Прототип приложения разработан для Android.

## О проекте
AR Beauty Guide - это приложение, предназначенное для мгновенного распознавания упаковок косметических средств с помощью камеры смартфона. При наведении камеры на продукт, поверх физической упаковки инициализируется интерактивный AR-интерфейс. 

Пользователь получает возможность быстро узнавать подробную информацию и рейтинг продукта, который оказался у него в руках. 

Интерфейс дополненной реальности включает три основных раздела:
1. Описание - официальные данные от производителя
2. Рейтинг - саммари отзывов из интернета, сгенерированное нейросетью в формате 2-3 предложений
3. Цены в магазинах - актуальная стоимость товара в нескольких сетях (Золотое Яблоко, Лэтуаль, Магнит Косметик)

## Технологический стек
* Движок: Unity
* AR движок: Vuforia
* База данных: JSON
* ИИ: ChatGPT
* UI дизайн: Illustrator
