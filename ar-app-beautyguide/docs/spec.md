# Техническое задание
Разработка мобильного приложения «AR Beauty Guide» с дополненной реальностью для распознавания косметики

### Концепция мобильного приложения 

Приложение предназначено для работы на мобильных устройствах операционной системы Android. 
Распознавание объектов осуществляется с использованием библиотеки Vuforia и технологии Image Targets.
При наведении камеры устройства на упаковку косметического продукта пользователю отображается AR-интерфейс, 
содержащий информацию о данном продукте. Интерфейс включает меню из 3 кнопок: «Описание», «Рейтинг», «Цены в магазинах». 

В рамках первого прототипа приложение поддерживает распознавание 15 товаров бренда ART&FACT.

### Цель проекта

Разработать на Vuforia прототип мобильного приложения для Android с технологий дополненной реальности для распознавания 
упаковки косметики и отображения справочной информации о товаре. 
Окончанием проекта считается рабочий apk файл, распознающий 15 предметов бренда ART&FACT. Срок сдачи проекта – 14.01.2026.

## Технические требования
### Функциональные требования
Пользователь приложения может выполнять следующие действия:
- Просматривать описание продукта
-	Просматривать рейтинг продукта
-	Просматривать цены на продукт в магазинах (Золотое Яблоко, Лэтуаль, Магнит косметик)

### Нефункциональные требования
Интерфейс приложения должен корректно отображаться на мобильных устройствах Android. 
Изображение с камеры должно отображаться во весь экран устройства. UI элементы должны чётко и различимо отображаться. 
Кнопки интерфейса должны реагировать на действия пользователя. 

При исчезновении цели (продукта) из кадра, меню продукта должно исчезнуть с экрана.

При запуске приложения без доступа к сети, на экране должно появляться всплывающее уведомление: «Для работы приложения необходим интернет. Проверьте подключение».

При наведении камеры на объект, которого нет в базе данных из 15 продуктов, приложение не должно выдавать ошибок.

База данных продуктов должна быть представлена json файлом. Сущность продукт должна иметь такие поля:
*	product_id (название Target в базе данных Vuforia)
*	product_title
*	product_description
*	product_rating
*	product_review
*	product_price_goldapple
*	product_price_letu
*	product_price_magnit

Рейтинг продукта должен быть сформирован при помощи ChatGPT и представлять собой текст объёмом 2-3 предложения на основе отзывов пользователей в интернете. 
Текст для поля рейтинг генерируется заранее на этапе подготовки базы данных и вручную заносится в JSON-файл для всех 15 продуктов.

### Требования к интерфейсу 
При разработке интерфейса необходимо использовать фирменный стиль, цвета – голубой (96B9D7), белый цвет (FFFFFF). 
Для текстовых элементов использовать легкочитаемый шрифт Inter.
