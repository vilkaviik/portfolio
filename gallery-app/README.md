# Планирование разработки мобильного приложения

При помощи приложения «Галерея» современные художники смогут делиться своими работами со всем миром. Основу приложения составляет коллекция всех работ, загруженных пользователями-художниками в общий доступ

# Структура репозитория

- /docs - документация,
- /docs/spec - техническое задание,
- /docs/userstory - пользовательские сценарии,
- /docs/bpmn-paysubscribe - bpmn схема процесса оплаты пользователем подписки
