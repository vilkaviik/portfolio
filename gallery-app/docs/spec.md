# Техническое задание

При помощи приложения «Галерея» современные художники смогут делиться своими работами со всем миром. Основу приложения составляет коллекция всех работ, загруженных пользователями-художниками в общий доступ. Все остальные пользователи имеют возможность просматривать работы, ставить им оценку «люблю», а также составлять собственные коллекции из произведений искусства. Работы художников могут быть помечены различными характеристиками: жанр или цветовая гамма.  

# Технические требования 

## Функциональные требования

При первом после скачивания открытии приложения пользователю необходимо авторизоваться при наличии аккаунта или зарегистрироваться в системе в противном случае. Регистрация аккаунта состоит из нескольких этапов. Первоначально пользователю предлагается выбрать роль в системе: художник или зритель. На главной странице приложения система предлагает только что авторизованному пользователю выбрать жанры, которые он хотел бы видеть в своей ленте. 

Возможности пользователя относительно картин включают такие действия:

- Пометить картину отметкой «Люблю». В таком случае картина добавляется в личную коллекцию пользователя «Избранное»

-	Отправить картину другому пользователю

-	Оставить комментарий относительно картины

-	Пожаловаться на картину (если она нарушает правила сообщества)

Действия, которые пользователь может выполнять относительно других пользователей:

-	Зритель может подписываться на аккаунт художника

-	Художник может подписываться на аккаунт художника

-	Любой пользователь может писать сообщение любому другому пользователю

-	Любой пользователь может оформить платную подписку на художника

-	Любой пользователь может создавать тематические чаты, обмениваться там сообщениями с другими пользователями, добавлять в чат других пользователей

## Нефункциональные требования

Данные хранятся в СУБД PostgreSQL. Мобильное приложение должно быть разработано в веб-фреймворке Django на языке программирования Python.

Для оформления платной подписки на художников система должна поддерживать несколько способов безопасной онлайн-оплаты. Приложение должно быть связано с различными онлайн-банками: Сбербанк, Т-Банк, Газпромбанк, ВТБ, АТБ, Райффайзенбанк. 

Приложение должно корректно отображаться на большинстве популярных сейчас моделях телефонов: Huawei, Apple, Honor, Xiaomi, Redmi, Apple, Samsung.

Процесс разработки ПО разделён на определённые этапы. Они включают в себя:
1.	Составление технического задания на основе собранных требований
2.	Разработка серверной части, клиентской части, базы данных 
3.	Тестирование, запуск
4.	Поддержка
